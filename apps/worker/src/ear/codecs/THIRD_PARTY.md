# Third-party codec notices

Ra repackages the pinned non-ML Opus decoder as a static server-only WASM module and a minified JavaScript adapter. No model weights are included. Package revisions and checksums are in `tools/ear/codecs.lock.json`. The common adapter retains upstream embedded puff code; Ra supplies a statically compiled Opus module. `@eshaz/web-worker` is a preparation dependency only and contributes no shipped runtime bytes. The Ogg framing parser is Ra code; codec-parser is not included.

These notices cover the Ear codec additions, not an inventory of every workspace dependency.
